# Test App showing SkiaCamera

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

It contains a SkiaCamera and a button to toggle whether the SkiaCamera is rendered or not.
A colored line is drawn from the center of the canvas to each corner.

## Get started

1. Install dependencies

   ```bash
   pnpm install
   ```

2. Run Expo Prebuild

   ```bash
   pnpm expo prebuild
   ```

3. Build and install the app

   ```bash
   pnpm expo run:ios
   ```
   or
   ```bash
   pnpm expo run:android
   ```
   optionally followed by `--device`

The non-boilerplate code is in `src/app/index.tsx`
